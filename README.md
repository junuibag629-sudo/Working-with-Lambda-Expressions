# 32 람다 표현식 사용하기

### 람다란
- 식의 형태로 되어있는 표현식
- 이름이 없는 함수를 간단하게 정의할 때 사용하는 방법
- 일반적으로 def를 사용하여 함수를 정의하지만, 람다 표현식을 사용하면 함수를 한 줄로 간결하게 작성할 수 있음

- 예시 코드
```
lambda x: x + 10
plus_ten = lambda x: x + 10
plus_ten(1)
```
결과
11

### 함수 활용
- 람다 표현식은 map, filter, reduce 함수와도 같이 활용할 수 있음

#### map에 객체 여러 개 넣기
```
a = [1, 2, 3, 4, 5]
b = [2, 4, 6, 8, 10]
list(map(lambda x, y: x * y, a, b))
결과
[2, 8, 18, 32, 50]
```
- 이렇게 리스트 두 개를 처리할 때는 lambda x, y: x * y 처럼 매개변수를 두 개 지정하면 됨

#### filter 사용하기
- filter는 반복 가능한 객체 특정 조건에 맞는 요소만 사용하여 True만 가져옴
```
a = [8, 3, 2, 10, 15, 7, 1, 9, 0, 11]
list(filter(lambda x: x > 5 and x < 10, a))
결과
[8, 7, 9]
```

#### reduce 사용하기
- reduce는 반복 가능한 객체를 함수로 처리한 뒤 누적해서 반환함
```
a = [1, 2, 3, 4, 5]
from functools import reduce
reduce(lambda x, y: x + y, a)
결과
15
```

## 심사문제: 파일 이름을 한꺼번에 바꾸기
### 1. 코드 작성규칙
- 여러 파일을 입력
- 적힌 파일의 숫자를 3개로 앞에는 0이 들어가도록함
- 리스트 형식으로 출력
- 파일명 처리는 문자열 포매팅과 문자열 메서드 사용

### 2. 작성시 시행착오
- .zfill() 이 코드가 숫자에 0을 붙여주지만 활용을 하지 못함

### 3. 실제 구현 내용
- 파일을 97.xlsx 이런 형식으로 여러 개 작성
- 출력하면 097.xlsx 이렇게 리스트 형식으로 출력

### 4. 전체 코드 정리
```
#표준입력:1.jpg 10.png 11.png 2.jpg 3.png
#표준입력:97.xlsx 98.docx 99.docx 100.xlsx 102.docx
files = input().split()
print(list(map(lambda x: x.split('.')[0].zfill(3) + '.' + x.split('.')[1], files)))
```
